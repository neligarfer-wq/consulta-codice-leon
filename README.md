# Consulta CoDiCe TIC · León

Webapp para consultar por nombre, localidad o código las modalidades del curso 2026/2027, con 220 centros activos.

Modalidades y niveles: LE_CoDiCeTIC_2026 definitivo.xlsx. Códigos: directorio oficial JCyL y fuentes oficiales complementarias.

Sin dependencias ni compilación. Los archivos index.html, style.css, app.js y data.js deben estar juntos.

Para GitHub Pages: Settings → Pages → Deploy from a branch → seleccionar la rama predeterminada y /(root).

La consulta utiliza las modalidades indicadas en el listado, sin calcular fechas de caducidad ni cursos futuros.
